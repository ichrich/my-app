# GameHub

Игровой портал с каталогом, новостями, событиями, личной библиотекой и панелью управления. Nuxt 3 рендерит публичные страницы на сервере. Nitro обслуживает REST API, Prisma хранит данные в PostgreSQL, Pinia хранит состояние авторизации.

## Локальный запуск

Требуются Node.js 22 или новее и Docker с Compose. Если PostgreSQL уже запущен, укажите его адрес в `.env`.

1. Скопируйте `.env.example` в `.env`.
2. Для входа в админку задайте `GAMEHUB_ADMIN_EMAIL` и собственный `GAMEHUB_ADMIN_PASSWORD` (от 12 символов). Первый запуск seed создаёт аккаунт, повторный сохраняет существующий пароль.
3. Выполните:

   ```sh
   docker compose up -d db
   npm ci
   npm run db
   node --env-file=.env prisma/seed.mjs
   npm run dev
   ```

Откройте `http://localhost:3000`. Публичные маршруты включают `/games`, `/news` и `/events`. Кабинет находится по адресу `/profile`, управление доступно на `/admin`.

## Данные

Стартовый каталог содержит 24 реальные игры и демонстрационный анонс Signal Zero. Арт реальных игр подгружается с CDN Steam. Популярность задана как редакционный порядок для демонстрации. Рейтинг, скриншоты и требования можно заполнить в админке. Новости и события представляют собой демонстрационный редакционный контент. Вкладка активности показывает последнее изменение каждой сохранённой игры.

## Развёртывание

Выполните `npm run build`, затем запустите `node .output/server/index.mjs` на Node-хостинге за HTTPS-прокси. Перед запуском примените схему к PostgreSQL. Задайте `DATABASE_URL` и `NUXT_PUBLIC_SITE_URL` в окружении процесса. Опубликованные страницы входят в `/sitemap.xml`.

`server/api/content` отвечает за чтение каталога, `server/api/admin` за управление контентом и ролями, `server/api/auth` за регистрацию и серверные сессии, `server/api/library` за библиотеку. Загруженные JPEG, PNG и WebP хранятся в базе. Сессии используют HttpOnly cookie и хэш токена в базе. В production cookie требует HTTPS.
